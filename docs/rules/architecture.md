# Architecture rules

## Where code goes

| Place | Holds | Example |
| :--- | :--- | :--- |
| `apps/api/src/` | Hono HTTP server, `/api/chat` streaming endpoint, `/api/session` routes, and `/mcp` HTTP transport wrapper | `apps/api/src/modules/chat/router.ts` |
| `apps/web/src/routes/` | TanStack Router file-based pages (`/`, `/s/$id`) | `apps/web/src/routes/s.$id.tsx` |
| `apps/web/src/components/reports/` | Visual report card templates rendered inside chat tool parts (`PlayerScoutingCard`, `PrematchLineupCard`, `PeerComparisonCard`) | `apps/web/src/components/reports/player-scouting-card.tsx` |
| `apps/web/src/components/` | Chat screen (`@anvia/react-ui`), sidebar, starter prompt chips, and tool call badges | `apps/web/src/components/chat-screen.tsx` |
| `packages/agents/src/` | `@anvia/core` agent, deterministic workflows (news sync, intent guard, visual schema validator), RAG retriever, MCP client, and `@anvia/core/evals` suite | `packages/agents/src/agent.ts`, `packages/agents/src/evals/` |
| `packages/mcp-server/src/` | Custom MCP producer (`liga1-intelligence-mcp`) with `server.ts`, `tools.ts`, `mcp-stdio.ts`, and `mcp-http.ts` | `packages/mcp-server/src/tools.ts` |
| `packages/db/src/` | Read-only PostgreSQL analytics pool, `pgvector` RAG query helpers, and Prisma 8 `PrismaMemoryStore` | `packages/db/src/index.ts` |

## Rules

1. **Clear package boundaries**:
   - `apps/web` never imports from `packages/db`, `packages/agents`, or `packages/mcp-server` runtime code. It talks to `apps/api` over HTTP (`/api/chat`, `/api/session`).
   - Shared TypeScript types and Zod schemas for visual cards live in a shared types file or package exported cleanly.
2. **Goal-oriented MCP tools (Day 17 rule)**:
   - Do not create 20 tiny table-level tools. Keep the MCP server focused on the 3 core user goals (`scout_players`, `get_prematch_context`, `get_player_report_data`).
3. **Never hand-edit generated files**:
   - `apps/web/src/routeTree.gen.ts` and Prisma generated contracts are generated by CLI scripts.
4. **Keep the Harness lean (Day 18 rule)**:
   - Give the agent `<= 6` well-described tools total (PostgreSQL MCP tools + News/Regulation RAG search + Web Search MCP + Visual Card renderer).
